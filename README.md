# พุทธพจน์ UI v5 (`putthapot-ui-v5`)

เว็บแอปพลิเคชันสำหรับศึกษาพระดำรัสจากพระไตรปิฎกควบคู่กับแผนภาพวงจรธรรมและการแยกชั้นหลักฐานอย่างชัดเจน

## โครงสร้างไฟล์ภายในชุด
- `index.html` — โครงสร้างหลักของหน้าจอ (Header, แถบหัวข้อด้านบน, แถบตัวกรองระดับหลักฐาน, พื้นที่แผนภาพวงจร และรายการเนื้อหา)
- `styles.css` — สไตล์ชีต รองรับทั้งโหมดกระดาษถนอมสายตา (Parchment) และโหมดกลางคืน (Dark Mode) พร้อมสีแยกชั้นหลักฐาน
- `data.js` — คลังข้อมูลพระสูตร (ชั้น **A พระดำรัส**) และคำอธิบายสังเคราะห์ (ชั้น **ห้อง เรียบเรียง**) แยกตามหัวข้อและโหนดวงจร
- `app.js` — ระบบโต้ตอบอัปเดตไฮไลต์หัวข้อ แผนภาพวงจร SVG แบบคลิกเลือกโหนดได้ และตัวกรองระดับหลักฐานแบบเรียลไทม์

## วิธีเปิดใช้งาน
1. แตกไฟล์ `putthapot-ui-v5.zip` ออกมาเป็นโฟลเดอร์ `putthapot-ui-v5`
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Safari, Firefox) ใช้งานได้ทันทีโดยไม่ต้องติดตั้งเซิร์ฟเวอร์เพิ่มเติม
